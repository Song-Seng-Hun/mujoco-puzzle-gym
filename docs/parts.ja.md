# 部品の一覧と属性

[READMEに戻る](README.ja.md) · [한국어](parts.md) · [English](parts.en.md)

パズル部屋は部品を組み立てて作ります。部品一つは`room.yaml`の`parts:`リストの一行で、**種類(`type`)と属性**でできています。部品どうしは`links:`で信号をつなぎます。この文書では、いま入っている部品とその属性を説明します。

## すべての部品に共通の属性

| 属性 | 意味 | 既定値 |
|---|---|---|
| `name` | 部品の名前。`links`や観測はこの名前で指します | 必須 |
| `type` | 部品の種類(下の一覧) | 必須 |
| `pos: [x, y]` | 部屋の中央を原点とした位置 [m] | 必須 |
| `random: [dx, dy]` | エピソードごとに位置を揺らす範囲 [m]。学習したポリシーが場所を覚えてしまわないようにします | `[0, 0]` |
| `require: all \| any` | つながった信号が複数あるとき、すべてオンが必要か、一つでよいか | `all` |

部品にはそれぞれ役割があります。点検(`mpg check`)と環境は、この役割から解く順序を計算します。

| 役割 | 意味 |
|---|---|
| `switch` | オン/オフの状態があり、信号を送ります |
| `gate` | つながった信号がオンになるまで道をふさぎます |
| `goal` | 体が着くと成功としてエピソードが終わります |
| `prop` | そのほかの飾りや障害物 |

## 内蔵部品

### `switch` — 床スイッチ(役割 `switch`)
体の中心が板の上に来るとオンになります。衝突はありません。

| 属性 | 意味 | 既定値 |
|---|---|---|
| `size: [w, h]` | 板の大きさ [m] | `[0.25, 0.25]` |
| `latch` | `true`なら一度踏むとオンのまま、`false`なら踏んでいる間だけオン | `true` |

### `door` — 引き戸(役割 `gate`)
壁のすき間をふさぐ板です。つながったスイッチがオンの間は壁の中へ滑って開き、オフになると閉じます。

| 属性 | 意味 | 既定値 |
|---|---|---|
| `width` | ふさぐすき間の幅 [m] | `0.5` |
| `axis: x \| y` | 板の向き | `y` |
| `thickness` | 板の厚さ [m] | `0.04` |
| `height` | 板の高さ [m] | `0.25` |
| `open_dir: 1 \| -1` | 開くときに滑る向き | `1` |

### `goal` — ゴール(役割 `goal`)
体の中心が半径の内側に入ると成功です。衝突はありません。

| 属性 | 意味 | 既定値 |
|---|---|---|
| `radius` | ゴールの半径 [m] | `0.15` |

## 部屋そのものの属性

| 属性 | 意味 |
|---|---|
| `size: [w, h]` | 部屋の内寸 [m]、原点が中央 |
| `wall: {thickness, height}` | 外壁の厚さと高さ |
| `walls:` | 内側の壁の一覧、各`{from: [x, y], to: [x, y]}` |
| `spawn: {pos, yaw, random}` | 出発位置と向き、エピソードごとに揺らす範囲`[dx, dy, dyaw]` |
| `links:` | 信号のつながりの一覧、各`{from: 部品, to: 部品}` |

## 新しい部品を作る

部品は`Part`を継承したPythonクラス一つです。属性は`cfg`から読み、役割は`role`で決めます。`register_part`で登録し、`task.yaml`の`plugins:`にモジュール名を書けば、`room.yaml`で`type`として使えます。例は[使い方ガイド](guide.ja.md)にあります。

## これから入る部品(マイルストーン2、設計中)

ボタン(壁・床)、圧力板、エリア・レーザーセンサー、受け箱、的、論理ゲートとカウンター、トランシーバー、信号源と電線、ワープとばね、罠、くちばしでつかむ物と装置(レバー、ダイヤル、引き出し、ディスペンサー)、自分で動くロボットと飼い主、牽引ロープ、車輪アドオンの装着台、破壊装置、チェックポイント、そしてこれらをまとめたパズルの組み立てプリセット。入りしだい、属性とあわせてこの文書に追加します。
