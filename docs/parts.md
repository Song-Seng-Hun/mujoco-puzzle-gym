# 부품 목록과 속성

[README로 돌아가기](../README.md) · [English](parts.en.md) · [日本語](parts.ja.md)

퍼즐 방은 부품을 조립해 만듭니다. 부품 하나는 `room.yaml`의 `parts:` 목록 한 줄이고, **종류(`type`)와 속성들**로 이루어집니다. 부품끼리는 `links:`로 신호를 잇습니다. 이 문서는 지금 들어 있는 부품과 각 속성을 설명합니다.

## 모든 부품의 공통 속성

| 속성 | 뜻 | 기본값 |
|---|---|---|
| `name` | 부품 이름. `links`와 관측에서 이 이름으로 가리킵니다 | 필수 |
| `type` | 부품 종류 (아래 목록) | 필수 |
| `pos: [x, y]` | 방 가운데를 원점으로 한 위치 [m] | 필수 |
| `random: [dx, dy]` | 매 에피소드 위치를 흔드는 범위 [m]. 학습한 정책이 자리를 외우지 않게 합니다 | `[0, 0]` |
| `require: all \| any` | 연결된 신호가 여러 개일 때 모두 켜져야 하는지, 하나만 켜져도 되는지 | `all` |

부품마다 역할이 정해져 있습니다. 점검(`mpg check`)과 환경은 이 역할로 풀이 순서를 계산합니다.

| 역할 | 뜻 |
|---|---|
| `switch` | 켜짐/꺼짐 상태가 있고 신호를 내보냅니다 |
| `gate` | 연결된 신호가 켜질 때까지 길을 막습니다 |
| `goal` | 몸이 닿으면 성공으로 에피소드가 끝납니다 |
| `prop` | 그 밖의 장식이나 장애물 |

## 내장 부품

### `switch` — 바닥 발판 (역할 `switch`)
몸 중심이 발판 위에 오면 켜집니다. 충돌은 없습니다.

| 속성 | 뜻 | 기본값 |
|---|---|---|
| `size: [w, h]` | 발판 크기 [m] | `[0.25, 0.25]` |
| `latch` | `true`면 한 번 밟으면 계속 켜짐, `false`면 밟고 있는 동안만 켜짐 | `true` |

### `door` — 미닫이 문 (역할 `gate`)
벽의 틈을 막는 판입니다. 연결된 발판이 켜지면 벽 속으로 미끄러져 열리고, 꺼지면 닫힙니다.

| 속성 | 뜻 | 기본값 |
|---|---|---|
| `width` | 막는 틈의 폭 [m] | `0.5` |
| `axis: x \| y` | 문판이 놓인 방향 | `y` |
| `thickness` | 문판 두께 [m] | `0.04` |
| `height` | 문판 높이 [m] | `0.25` |
| `open_dir: 1 \| -1` | 열릴 때 미끄러지는 쪽 | `1` |

### `goal` — 골 (역할 `goal`)
몸 중심이 반경 안에 들어오면 성공입니다. 충돌은 없습니다.

| 속성 | 뜻 | 기본값 |
|---|---|---|
| `radius` | 골 반경 [m] | `0.15` |

## 방 자체의 속성

| 속성 | 뜻 |
|---|---|
| `size: [w, h]` | 방 안쪽 크기 [m], 원점이 가운데 |
| `wall: {thickness, height}` | 바깥벽 두께와 높이 |
| `walls:` | 안쪽 벽 목록, 각 `{from: [x, y], to: [x, y]}` |
| `spawn: {pos, yaw, random}` | 출발 위치와 방향, 매 에피소드 흔드는 범위 `[dx, dy, dyaw]` |
| `links:` | 신호 연결 목록, 각 `{from: 부품, to: 부품}` |

## 새 부품 만들기

부품은 `Part`를 상속한 파이썬 클래스 하나입니다. 속성은 `cfg`에서 읽고, 역할은 `role`로 정합니다. 만든 부품은 `register_part`로 등록하고 `task.yaml`의 `plugins:`에 모듈 이름을 적으면 `room.yaml`에서 `type`으로 쓸 수 있습니다. 예시는 [사용 안내](guide.md#새-부품-관측-보상-알고리즘-넣기)에 있습니다.

## 앞으로 들어올 부품 (마일스톤 2, 설계 중)

버튼(벽·바닥), 압력판, 구역·레이저 센서, 받침 상자, 과녁, 논리 게이트와 카운터, 트랜시버, 신호기와 전선, 워프와 스프링, 함정, 부리로 집는 물체와 장치(레버, 다이얼, 서랍, 디스펜서), 스스로 움직이는 로봇과 주인, 견인 끈, 바퀴 애드온 장착대, 파괴기, 체크포인트, 코인과 코인 잠금, 그리고 이것들을 묶은 퍼즐 조립 프리셋. 들어오는 대로 이 문서에 속성과 함께 추가합니다.
