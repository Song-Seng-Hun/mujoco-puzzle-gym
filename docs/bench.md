# 속도 측정 (R13)

## 1차 측정: 걷기만 (2026-11-11, PR A)

`uv run mpg bench --json --seconds 10 --procs 4,8,12,16`

- 기계: Mac Studio `Mac16,9`, `Apple M4 Max` (`sysctl -n machdep.cpu.brand_string`), 16코어(성능 12 + 효율 4), 메모리 64 GB
- 소프트웨어: Python 3.12, MuJoCo 4.0.0, onnxruntime(CPU, 스레드 1), better-actuator-models 1.0.3
- 측정 내용: 평지 위 몸 하나, 명령 vx=0.3 고정. 걷기 1스텝 = 정책(ONNX) 1회 + BAM 계산과 물리 4스텝(5 ms × 4 = 20 ms). 위층 1스텝(10 Hz) = 걷기 5스텝 = 물리 20스텝.
- 병렬: 프로세스 N개가 각자 환경 하나를 돌림(`multiprocessing` spawn). 넘어짐 0회.

| 설정 | 걷기 스텝/초 | 물리 스텝/초 | 위층 스텝/초(추정) |
|---|---:|---:|---:|
| 단일 프로세스 | 3,531 | 14,122 | 706 |
| 병렬 4 | 12,300 | 49,201 | 2,460 |
| 병렬 8 | 24,147 | 96,586 | 4,829 |
| 병렬 12 | 35,300 | 141,202 | 7,060 |
| 병렬 16 | 38,570 | 154,279 | 7,714 |

## 2시간 추정

- 가장 빠른 설정(병렬 16): 위층 7,714 스텝/초 × 7,200초 ≈ **5,550만 스텝**.
- 병렬 12(성능 코어 수, 학습기에 코어를 남기는 설정): 7,060 × 7,200 ≈ 5,080만 스텝.
- 이 숫자는 상한이다. 아직 빠진 것: 방(벽·문·발판) 접촉, 부품 상태기계, 관측·보상 계산, `SubprocVecEnv` 프로세스 간 통신, PPO 업데이트(같은 CPU 사용). 이것들은 PR B 끝(12단계 `mpg bench` 전체 측정)에서 다시 잰다.
